Features

Why PGlove?

Built for the brave. Breaks beautifully.

⚡

Daily Updates

We push code every 12-24 hours. You get new features before we even test them.

🐞

Built-in Bug Reporter

One-click to file an issue on GitHub. You will find bugs.

🔬

Experimental APIs

Try WebGPU, new CSS features, and Chrome flags months before stable.

💥

Crash Recovery

Recovers your tabs 80% of the time. The other 20%? Adventure.

🧪

A/B Test Features

Half get Feature X, half get Y. You're part of the experiment.

🌙

Auto Dark Mode

Even websites without dark mode get forced into it. Eyes will thank you.
